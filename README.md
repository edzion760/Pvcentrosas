# PVCENTRO App - Sistema de Control de Ventas, Inventario y Contabilidad

## Descripción General
Aplicación PWA Offline-First para la gestión integral de PVCENTRO (San Gil y Socorro) con sincronización mediante Google Sheets y Google Apps Script.

## Componentes del Proyecto
1. `index.html` - Interfaz principal de la aplicación PWA.
2. `sw.js` - Service Worker para soporte offline continuo.
3. `manifest.json` - Configuración para instalación en celular y escritorio.
4. `google_apps_script.gs` - Código backend para Google Apps Script.
5. `GUIA_DESPLIEGUE.md` - Paso a paso para configuración y publicación.
